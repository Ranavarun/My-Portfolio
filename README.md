# Varun Rana — CRM Specialist Portfolio

A responsive, dark editorial-style portfolio for a CRM professional working across Zoho and Salesforce.

## Publish it with GitHub Pages (GitHub Actions)

1. Create a public GitHub repository, for example `varun-rana-portfolio`.
2. Upload the contents of this folder to the repository root (make sure `.github/workflows/deploy.yml` is included).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **GitHub Actions**.
5. Push to the `main` branch. The workflow deploys the site automatically.
6. Open **Actions** to confirm the deployment. Your site URL will be shown in the `deploy` job.

## Personalize before publishing

Search `index.html` and update:
- `hello@varunrana.dev` with your real email.
- The project cards with real projects, screenshots, outcomes, and GitHub repository links.
- The career timeline with exact titles and dates you want public.
- Skill labels to match tools you have actually used hands-on.

The project cards are currently labelled as concepts/practice directions. Keep them that way until you replace them with completed work. Avoid publishing confidential client or employer information.
